# Security Policy

This repository hosts a personal portfolio website. It is a static site with no
backend, no accounts, and no user data, so the security surface is limited to the
project's dependencies and its build and deploy pipeline.

## Reporting a vulnerability

Please report security issues privately, not through public issues:

- Preferred: GitHub's private vulnerability reporting, via the repository's
  **Security** tab, then **Report a vulnerability**.
- Email: hestia.tu2cy@8alias.com

I will acknowledge valid reports as soon as I can and address them promptly.
